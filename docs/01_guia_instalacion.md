# 🛠️ 01. Guía de Instalación y Configuración

Este documento detalla los pasos para levantar el entorno de desarrollo local utilizado en este proyecto de Big Data.

## Requisitos Previos
- **Sistema Operativo:** Windows 10/11 (con WSL2 habilitado) o Linux/macOS.
- **Python:** Versión 3.10 o superior.
- **Docker Desktop:** Instalado y corriendo.
- **Git:** Para control de versiones.
